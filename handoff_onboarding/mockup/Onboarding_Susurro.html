03 · Spec resumida

Decisiones finales — extracto

Lo crítico para Claude Code. La spec completa con contratos de datos, lógica de estado y plan de archivos vive en README.md.

A · Estructura

Dos plantillas, no cinco

Toda la app del onboarding son dos componentes de slide:

  • OnboardingBottomSlide · slides 1, 2, 3, 5
  • OnboardingFormSlide · slide 4

Shell común Onboarding.jsx maneja state machine, swipe, dots y skip.

B · Slide 3 behavior

Cuatro estados visibles

  • idle · placeholder, CTA disabled
  • typing · borde focus, CTA enabled (texto ≥ 3)
  • loading · loader + frase rotatoria 2.5s
  • response · card revelada con fade-up 600ms

error mapea al mismo render que response, sólo cambia el origen del payload.

C · Animaciones

Tres movimientos

  • Slide ↔ slide: translateX 280ms · ease-out
  • Respuesta del slide 3: fade-up 600ms cubic-bezier(.22,.61,.36,1)
  • Partículas estáticas (sin parallax — costo gratis, gana en performance)

Respetar prefers-reduced-motion: desactivar fade-up y translateX, mostrar instantáneo.

D · API · Claude

Sonnet 4.5 · prompt acotado

  • Modelo: claude-sonnet-4-5
  • Max tokens: 320 (objetivo $0.002/usuario)
  • Timeout: 8000ms
  • Output: { comprension, cita, autor, marco }

El prompt exacto lo define Claude Code en api/anthropic.js.

E · Persistencia

Lo que se guarda en Supabase

  • profiles.nombre · padre/madre
  • children · nombre, fecha de nacimiento, sexo, foto (opcional)
  • profiles.intenciones · array de chips
  • profiles.contexto_inicial · texto del slide 3, si lo escribió

El texto del slide 3 NO se guarda como episodio en borrador (decisión de diseño separada).

F · Navegación

Dots, skip, swipe

  • Dots: 5 · actual, completados, pendientes
  • Skip arriba: 1, 2, 4 — no en 3 ni 5
  • Skip inline en 3: "Saltar este paso"
  • Swipe lateral: habilitado · respeta el límite (no swipe-back si CTA disabled)
G · Idioma

Tuteo neutro

Español neutro/chileno. Puedes, tienes, fíjate. Nunca voseo argentino. El badge del slide 5 usa la forma corta "Bienvenido/a, [Nombre]" para evitar overflow con nombres largos.

H · Tokens

Sólo tokens base

De colors_and_type.css. Cero aliases (--color-cream, --color-ink…). Gradientes y partículas viven en el CSS Module del componente, no en index.css.
